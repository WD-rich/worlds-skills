# 灰烬回路 / Ashfall Circuit · Scale Edition

## 规模

- 10 个城区，60 个空间节点
- 8 个派系，40 个角色
- 50 个确定性时间步，6 个快照
- 7 类公共资源，至少 80 条有向关系

## 五幕结构

1. **密钥与信号浮现（1–10）**：旧水网密钥的残片在多个城区被同时听见。
2. **水与市场收紧（11–20）**：蓝盐和净水产能成为公开交易与暗中配给的中心。
3. **派系动员（21–30）**：八个派系开始把个人关系转化为路线、债务和护送。
4. **尘暴与设施故障（31–40）**：灰尘前沿压过城市骨架，维护无人机的旧指令重新出现。
5. **多方汇合（41–50）**：水、电、记忆产权和晨钟残权汇入同一个可分支节点。

## 运行原则

每一步先消耗资源，再应用生产和维修，然后处理角色行动，最后追加事件。确定性 Provider 按“生存 > 修复 > 移动 > 社交”排序，同优先级按 actor ID 排序。

## 与 0.1 的关系

这是 `ashfall-circuit-v0.1` 的扩展版，使用独立 workspace ID 和 schema 版本，不修改旧快照；旧空间 ID 通过 aliases 保留叙事兼容。
