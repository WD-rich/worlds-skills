# Story Chronicler

Use this skill when a running world needs a readable history, a feed of significant moments, or a daily recap.

## Rules

- derive content only from validated records and attributed dialogue;
- keep event IDs, participants, time, location, and uncertainty as provenance;
- score significance from explicit tags and state changes, not arbitrary prose;
- store summaries and quote candidates as derived content that can be regenerated;
- never promote a highlight to a world fact without a runtime event.
