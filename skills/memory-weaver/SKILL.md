# Memory Weaver

Use this skill when an event should become memorable, when an actor needs relevant context, or when a tick/day requires consolidation or reflection.

## Rules

Memories are observations or interpretations available to a character; they are not authoritative world facts. Store provenance, source record IDs, game time, location, participants, emotional signal, importance, uncertainty, retention, and supersession metadata. Retrieval must be bounded and explainable by recency, relevance, relationship, location, and current need. Reflection and diary entries remain derived content and never rewrite the event log.
